# RFC: fleetctl (retired)

The fleet toolchain (`fleetctl`, `pkg/fleettest`, `pkg/fleetcfg`, `pkg/kubewho`)
was retired in v0.5.0, superseded by [github.com/truvity/gemaal](https://github.com/truvity/gemaal)
(design: `docs/design.md` there). ocictl is again pure build-time OCI tooling:
`crdctl` + `helmctl`.
